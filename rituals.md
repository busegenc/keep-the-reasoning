# Rituals

Skills you stop exercising fade — faster than you'd guess. These keep you calibrated. Put them in your calendar; checking the machine is real work, and work that isn't scheduled doesn't happen.

## Weekly

- Do one small, real task **without** an agent — pick something that would hurt to forget.
- Check your review capacity: is finished agent work piling up faster than you can stand behind it? If yes, don't open another session. Tighten the checks so less needs you, or slow down.

## Monthly

- List what you've stopped doing since you started using agents.
- Decide which of those you're consciously letting go — and which you want back.
- Ask yourself: *how lost would I be if AI didn't exist tomorrow?*

## Ongoing

- Every time an output doesn't meet your bar, write down **why** — as a rule in your agent config, a hook, or a test — so it doesn't happen again. That's how taste compounds.
- When you hit something you don't understand, learn it properly instead of pasting a one-line explanation.
